# הפרומפטר של שמרית

אפליקציית רשת לצילום סרטונים עם טקסט רץ ליד העדשה.

- מדביקים דף טקסטים או כותבים בעצמך, ולוחצים ״לצילום״.
- המצלמה הקדמית נפתחת, והטקסט רץ למעלה בגדול, ממש ליד העדשה. כשהטלפון שוכב, הטקסט עובר לצד של המצלמה.
- כדי להתחיל מאמצע הדף, נוגעים בשורה שממנה מתחילים ואז ״לצילום״.
- ההקלטה נשמרת בטלפון כקובץ וידאו, גם כשהיא ארוכה.

הטקסט וההגדרות נשמרים רק בדפדפן של הטלפון, ולא נשלחים לשום מקום.

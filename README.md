# הפרומפטר של שמרית

אפליקציית רשת לצילום סרטונים עם טקסט רץ ליד העדשה.

- מדביקים טקסט ובוחרים סוג סרטון: ריל, סטורי, הדרכה או אחר.
- לכל סוג יש הנחיות צילום, ומצלמה שנפתחת בכיוון ובהגדרות שלו, עם קווי עזר למיקום.
- ההקלטה נשמרת בטלפון כקובץ וידאו.

התסריטים וההגדרות נשמרים רק בדפדפן של הטלפון, ולא נשלחים לשום מקום.
